# ClioSort MCP

ClioSort connects coding agents to managed application data. Read GitHub repository scan results, import detected records into managed collections, and manage collections and records from your MCP client.

## Connect

Add `https://cliosort.com/api/mcp` as a remote server in an MCP client that supports OAuth. If your client uses an `mcpServers` JSON configuration, merge the entry from [mcp.json](mcp.json) into your configuration. Sign in to ClioSort and approve access when prompted.

Some data-management tools require an active ClioSort plan. See the [ClioSort MCP documentation](https://cliosort.com/docs#mcp) for setup and examples.
